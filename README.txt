JOLLIBEE LANDING PAGE

Đây là landing page một trang, tập trung giới thiệu món ăn và dẫn khách sang kênh đặt hàng chính thức.

Cấu trúc:
- index.html: nội dung landing page
- style.css: giao diện responsive cho máy tính và điện thoại
- script.js: cuộn mượt tới phần nội dung
- assets/: mascot
- images/: logo và ảnh combo

Xem trên máy:
1. Giải nén ZIP.
2. Mở index.html trong Chrome/Edge.

Đưa lên GitHub Pages:
1. Tải toàn bộ nội dung trong thư mục này lên repository.
2. Vào Settings > Pages.
3. Chọn Deploy from a branch, nhánh main, thư mục /(root).
4. Lưu và chờ GitHub Pages triển khai.

Lưu ý: Đây là landing page demo không chính thức. Các nút đặt món mở website chính thức Jollibee. Hình ảnh ngoài cần kết nối Internet; giá và ưu đãi không được khẳng định trong bản demo.
